# neolithic-farming-game
Educational game on the spread of farming during the Neolithic in parts of the Old World. Created initally with Claude as an independent project for the SciComm Certificate Program 2026 (Koç University Office of Sustainability) by Zeineb Grissa (1st year PhD student in Archaeology). Explore regions, learn archaeological evidence, complete quizzes, earn XP, and unlock new areas.
